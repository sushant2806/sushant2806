## Featured Work

### Cloud Stack Club Platform

Official website and club-management platform for **Cloud Stack Club, Chandigarh University**: a public site for events, registration and gallery, plus a protected admin dashboard for members, events, emails and content. Under active development.

**My role:** contributor. The project is led by [@Utkrisht-Utpal](https://github.com/Utkrisht-Utpal); my work is submitted as pull requests from my fork, with 50+ merged so far.

**What I built and improved**

- **Admin dashboard:** merged the member application and directory views, added member-type filters with counts and a recent-members toggle, and improved the event registration directory, toolbars and confirmation toasts.
- **Event tooling:** added a rich-text toolbar for event descriptions and rules, extended the "Configure rules" feature, and improved the custom dropdown used in event registration questions.
- **Responsive UI and polish:** phone-responsiveness fixes across event, feedback and admin screens, scroll-lock on popups, skeleton loading on the team page, and dark-theme fixes.
- **Workflow:** worked from tracked issues and feature branches, with each change reviewed and merged through a pull request.

**Stack** (from the project README): React 19 · TypeScript · Vite · Tailwind CSS v4 · Supabase (PostgreSQL) · Cloudflare R2 · Vercel

[Live site](https://cloudstack-official.vercel.app) &nbsp;·&nbsp; [My fork](https://github.com/sushant2806/Cloud-Stack-Club) &nbsp;·&nbsp; [Upstream repository](https://github.com/Utkrisht-Utpal/Cloud-Stack-Club) &nbsp;·&nbsp; [My merged pull requests](https://github.com/Utkrisht-Utpal/Cloud-Stack-Club/pulls?q=is%3Apr+is%3Amerged+author%3Asushant2806)
